Responsive Pricing Cards Section

A modern and responsive pricing cards section built using HTML, CSS, and JavaScript.

This project was created as part of Task 4 for the SpireX Foundation technical training.

Features

- Responsive pricing card layout
- Three pricing plans
- Basic, Professional, and Premium plans
- Monthly pricing display
- Feature comparison
- "Most Popular" highlighted plan
- Interactive "Get Started" buttons
- JavaScript alert for selected plans
- Smooth hover animations
- Responsive design for desktop, tablet, and mobile
- Professional and clean user interface
